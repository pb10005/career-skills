# 判断の材料

ヒアリングが止まったとき、比較軸を作るとき、選択肢が2つしか出てこないときに読む。**枠組みを本人に押し付けず、質問を作るための材料として使う。**

## 不満の切り分け表

不満の実体がどこにあるかで打ち手が変わる。ここを間違えると、転職しても同じ問題に当たる。

| 不満の実体 | 兆候 | 有効な打ち手 |
|---|---|---|
| 上司・人間関係 | 特定の人物の名前が繰り返し出る。部署が変われば解決すると本人も薄々思っている | 異動、上司の異動を待つ、社内公募。転職は最後の手段 |
| 業務内容 | 「この仕事に意味を感じない」「作業になっている」 | 担当変更、役割の追加、社内の別職種へ。それが無理なら転職 |
| 報酬 | 他社の水準を知って不満が出た。仕事自体は嫌いではない | 交渉、昇格要件の確認、等級制度の把握。**転職は手段の1つであって唯一ではない** |
| 成長の頭打ち | 「ここにいても学べることがない」「5年後の自分が見えてしまう」 | 社内で新規領域へ、または転職。**これは転職が有効なことが多い** |
| 労働時間・場所 | 生活との衝突が具体的 | 制度の確認・交渉が先。制度があるのに使えていないだけのことがある |
| 会社の将来 | 業績・事業の方向への不安 | 情報の確度を確認する。不安と事実を分ける |
| 疲弊・消耗 | 「何をしたいか分からない」「考える気力がない」 | **まず休む。この状態で重大な意思決定をしない。** 判断を延期すること自体を計画に入れる |

最後の行が重要。**消耗しきった状態での転職判断は精度が落ちる。** 有給・休職・異動で状態を戻してから決める、という選択肢を必ず提示する。健康の問題が絡むなら、キャリアの枠内で処理せず専門家に相談する項目としてアクションに分ける。

## 「移せるもの」の棚卸し

転職で持っていけるものと、置いていくものを分ける。本人は前者を過小評価していることが多い。

**持っていけるもの**

- 職種のスキル（設計、営業、分析、折衝など）
- 業界知識・ドメイン知識 — 同業界なら強い資産、異業界ならほぼゼロになる
- 実績と、それを語る力
- 社外の人的ネットワーク
- 資格・学位

**持っていけないもの**

- 社内の人間関係と信用の蓄積 — **これが最も過小評価される。** 「話が通る」「任せてもらえる」状態は、転職後にゼロから作り直しになる
- 社内固有のツール・プロセスの習熟
- 現在の等級・肩書きの通用度
- その会社での実績の文脈（同じ実績でも、外から見ると評価が変わる）

「置いていくもの」を明示すると、転職のコストが具体的になり、比較が正直になる。

## 選択肢を広げる問い

選択肢が「転職する / しない」の2つしか出てこないときに使う。

- 「今の会社の中で、この不満が解ける配置はありますか。制度上、申請できますか」
- 「同じ職種で業界を変える案と、同じ業界で職種を変える案は、それぞれどう見えますか」
- 「今すぐ動く案と、1年準備してから動く案では、何が変わりますか」
- 「その転職先で3年働いた後、次はどこに行けますか」（**出口を確認する。入口だけで選ぶと次で詰まる**）
- 「もし年収が変わらないとしたら、それでもその選択をしますか」（報酬以外の動機を分離する）
- 「一番動きたくない理由は何ですか」（**制約の正体が出てくる。多くは家庭・住宅ローン・時期の問題**）

## 比較軸の作り方

軸は本人の言葉から作る。汎用の軸をそのまま当てない。よく使われるもの:

| 軸 | 見るポイント |
|---|---|
| 年収 | 額面だけでなく、賞与の変動幅、退職金、福利厚生、残業代の扱い |
| 裁量 | 何を自分で決められるか。予算・人・技術の選定 |
| 学べること | 3年後に何ができるようになっているか |
| 安定性 | 事業の継続性、雇用形態、業界の構造 |
| 時間・場所 | 実際の運用（制度があるかではなく、使われているか） |
| 可逆性 | 失敗したとき戻れるか。**戻れない選択は期待値が高くても慎重に** |
| 実現までの時間 | 動き出してから結果が出るまで |

重み付けは Stage 3 の「今いちばん削れないもの / 削れるもの」から決める。**全軸を等価に扱うと比較にならない。**

## オファー・求人票を比較するとき

複数の選択肢が具体的な求人やオファーの形で存在する場合。

- **額面の年収だけで比べない。** 固定残業代の有無と時間数、賞与の実績（規定ではなく実績）、退職金の有無、住宅手当などの手当、ストックオプションの条件を並べる
- **職位の名前を比べない。** 同じ「マネージャー」でも、人数・予算・採用権限の有無で実態が違う。**何人・いくらを見るのかを確認する**
- **入社後の最初のミッションを聞く。** これが曖昧な求人は、入ってから期待値がずれる
- **なぜこのポジションが空いているのかを聞く。** 増員なのか欠員補充なのか。欠員なら前任者がなぜ辞めたのか
- **面接した人が上司になるのかを確認する。** Stage 2 で不満の実体が上司だった人ほど重要

## 転職以外の選択肢

見落とされやすいので、該当しそうなら必ず提示する。

- **社内公募・異動** — 制度があるのに知られていないことが多い。申請時期が年1回のこともあるので、時期の確認をアクションにする
- **役割の追加** — 転職せずに、今の職務に新しい責任を足す交渉。マネジメント経験が欲しい場合に有効
- **副業からの助走** — 方向を試してから移る。可逆性が高い
- **時期をずらす** — プロジェクトの区切り、賞与、家庭の事情。**半年ずらすだけで条件が変わることがある**
- **進学・専門教育** — 資格が参入要件になっている領域へ移る場合
- **独立・フリーランス** — 可逆性が低いので、収入の見通しと、戻る道の有無を必ず確認する

## ライフイベントと干渉する論点

出産・育児・介護・住宅購入が絡む相談では、キャリアの良し悪しとは別に**制度上のタイミング**が選択肢を縛る。ここを見落とすと、決めた後に「その時期には動けない」と分かって検討をやり直すことになる。

**制度の要件は改正されるし、勤務先の規定によっても違う。断定せず、確認すべき論点として提示し、確認そのものをアクションに入れる。** 一般論で答えると生活の判断を誤らせる。

確認を促す論点:

| 論点 | 何を確認するか |
|---|---|
| 育児休業 | 取得要件に勤続期間の条件があるか（転職直後だと満たさないことがある）。転職先の規定と実際の取得実績 |
| 産休・育休中の給付 | 加入している保険・雇用保険の扱い。転職で空白期間が生じる場合の影響 |
| 社会保険の継続 | 退職から入社までに空白が空く場合の手続きと負担 |
| 試用期間 | 転職先の試用期間中に大きなライフイベントが重なると、双方にとって難しい時期になる |
| 住宅ローン審査 | 勤続年数が審査項目になることがある。**購入予定があるなら、審査の時期と転職の順序を確認する** |
| 賞与・退職金 | 支給の基準日と在籍要件。数週間ずらすだけで金額が変わることがある |
| 有給の残日数 | 退職時の消化可否。転職先の付与時期 |

**時期の制約は選択肢を減らすとは限らない。** 「動くなら出産前」「育休明けに動く」「1年待つ」はいずれも独立した選択肢であり、Stage 5 で並べて比較する。制約が分かることで、かえって決めやすくなることが多い。

配偶者の就業状況・転勤可能性も聞く。世帯としての意思決定なのに、本人だけの条件で検討してしまうことがある。

## 情報の確度を扱う

キャリアの判断は不確実な情報の上に立つ。**確度の違うものを混ぜない。**

| 確度 | 例 | 扱い |
|---|---|---|
| 事実 | 現在の年収、在籍期間、制度の有無 | そのまま使う |
| 確認できる | 求人票の条件、公開されている統計 | 出典を書く |
| 伝聞 | 「あの会社は残業が多いらしい」 | 伝聞と明記する。確認をアクションにする |
| 推定 | 「この経験なら年収は上がりそう」 | **推定と明記する。数字を装わない** |

戦略メモの「前提と再検討の条件」には、推定と伝聞に依存している部分を書く。**それが崩れたら結論を見直す、という線をあらかじめ引いておく。**
